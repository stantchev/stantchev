## 👨‍💻 About Me

Most SEO specialists stop at the audit. I don't.

I come from the search side — technical SEO, content strategy, crawl budgets, Core Web Vitals — but I got tired of handing devs a spreadsheet and hoping for the best. So I started building the fixes myself. Now I sit in the overlap: the person who can diagnose *why* a page isn't ranking **and** ship the code that fixes it.

- 🔍 &nbsp;**Technical SEO** — crawlability, indexation, structured data, content decay, Core Web Vitals
- ⚙️ &nbsp;**Front-end** — building with **React**, **Next.js**, and **Node.js**
- 🤖 &nbsp;**AI automation** — currently deep in **PHP** and shipping LLM-powered tooling that automates the boring parts of SEO
- 🔌 &nbsp;**Open-source author** — WordPress plugins built to solve real problems I ran into on real client sites:
  - 📝 &nbsp;[**Quick Content Notes**](https://github.com/stantchev/QuickContentNotes-WordPress-Plugin) — inline editorial notes, so feedback lives where the content does
  - 📉 &nbsp;[**Content Decay Monitor**](https://github.com/stantchev/content-decay-monitor-wordpress-plugin) — catches declining content before it drags your rankings down with it
- 💬 &nbsp;Always up for talking SEO, Node.js, React, or AI automation → [stanchev.bg/kontakti](https://stanchev.bg/kontakti)
